- **الملاحظة:** الصياغة السابقة ذكرت أن Super Owner هو المالك الوحيد وأن التفويض لا ينقل الملكية، لكنها لم تفصل بما يكفي نطاق سلطته العليا على جميع أجزاء المنصة والتطبيقات والواجهات والعمليات والأنظمة والالتزامات.
- **التعديل:** إضافة مادة مستقلة شاملة في الدستور والرؤية توضح الملكية العليا والسلطة النهائية، ونطاق الصلاحيات، وحق التفويض والسحب، وعدم علو أي دور إداري أو تقني، والتمييز بين سيادة المالك وضوابط التنفيذ الآمن وحدود القانون والعقود وحقوق الأعضاء.
- **الحالة:** أُدرج توثيقياً على فرع التطوير؛ بانتظار مراجعة المالك واعتماده النهائي للإصدارين.
- **حدود التفسير:** لا تنشئ هذه المادة بذاتها نقلاً لحقوق ملكية فكرية أو حقوقاً في أصول الغير، ولا تلغي قوانين أو عقوداً أو موافقات لازمة، ولا تمنح المساعد صلاحية تنفيذ إنتاجية دون موافقة مستقلة.
