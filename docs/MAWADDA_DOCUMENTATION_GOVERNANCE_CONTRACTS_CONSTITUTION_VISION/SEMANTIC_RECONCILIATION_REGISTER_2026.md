## 1. منهج المصالحة وحالات السجل

- **معتمد:** يوجد قرار صريح محدد المصدر والتاريخ.
- **مرجع حاكم:** وثيقة تنظيمية نافذة لتطبيق قرار معتمد، دون أن تنشئ بذاتها موافقة جديدة.
- **اقتراح/خطة:** تصور أو توصية لم تعتمد كقرار نهائي.
- **قيد التنفيذ / منفذ جزئياً:** توجد أعمال أو شيفرة، لكن دورة القبول لم تكتمل.
- **منفذ ومختبر آلياً:** توجد أدلة اختبار على SHA معلوم؛ لا تعني قبول جهاز أو إطلاقاً.
- **معلق/غير محسوم:** توجد فجوة قرار أو موافقة.
- **متعارض تاريخياً:** مصدر أقدم يخالف قراراً أحدث؛ يحفظ للأرشيف ولا يطبق في موضع التعارض.
- **مكرر/مكافئ:** وثيقة أو بند يعيد صياغة المصدر نفسه؛ لا يحذف، بل يربط بالمعرف الأصلي.
- **غير متحقق دلالياً:** موجود في الجرد لكن لم تُقرأ مادته كاملة بعد.

التاريخ يميز بين تاريخ القرار، وتاريخ الوثيقة، وتاريخ commit، وتاريخ اسم الملف. لا يستخدم تاريخ اسم الملف لإثبات اعتماد. كل ادعاء تنفيذ يحتاج SHA وأدلة تشغيل.

5. تقرير التدقيق أو الخطة أو المقترح لا يصبح قراراً بمجرد رفعه إلى GitHub.
