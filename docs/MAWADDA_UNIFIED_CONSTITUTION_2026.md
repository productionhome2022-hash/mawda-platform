## 1. الهوية والغاية والمبادئ العليا

1. الاسم العربي: **مودة**؛ الاسم اللاتيني: **MAWADDA**؛ اسم المشروع التقني: Mawdda Platform 2026.
2. مودة منصة اجتماعية متعددة اللغات والمنصات للتواصل الإنساني والمجتمعي والصداقة والتعارف الهادف والعلاقات الجادة، بما فيها نوايا الارتباط والزواج حيث يسمح القانون وتتحقق شروط العمر والسلامة.
3. اللغات المستهدفة: العربية والإنجليزية والفرنسية والإسبانية، مع دعم RTL/LTR والنص المختلط.
4. ترتيب الأولويات: سلامة الأعضاء وكرامتهم وخصوصيتهم وموافقتهم؛ صحة الهوية والصلاحيات والبيانات والسجلات المالية؛ الاعتمادية والأداء وإمكانية الوصول؛ جودة التجربة؛ ثم النمو التجاري الشفاف.
5. يحظر تقديم وظائف أو أرصدة أو مشتريات أو توثيق أو تحليلات أو توافر على أنها حقيقية دون وجود تنفيذ ودليل. يحظر التضليل والأنماط القسرية والادعاءات غير المثبتة.

## 2. ترتيب المرجعية وحسم التعارض

ترتيب المرجعية:
1. أحدث موافقة صريحة ومحددة النطاق من المالك، مع حفظ الموافقات السابقة وتاريخها.
2. هذا الدستور بعد اعتماد المالك؛ وإلى حين ذلك يبقى إصداراً موحداً للمراجعة ولا ينسخ قرارات سابقة.
3. سجل القرارات المعتمدة، مع معرف القرار ومصدره وحالته ونطاقه.
4. الرؤية الشاملة ومواصفات المجالات والعقود والاتفاقيات المتخصصة.
5. الميثاق الهندسي وسجل التتبع والكود والاختبارات وتقارير التدقيق.
6. المحادثات وسجلات Termux مصادر سياق وإثبات عند حفظها؛ ولا تحل محل توثيق GitHub.

كل بند يصنف على حدة: معتمد، مقترح، قيد التنفيذ، منفذ جزئياً، منفذ، مختبر آلياً، مقبول على جهاز/بيئة، جاهز للإطلاق، مؤجل، مرفوض، أو محظور. لا يعني اعتماد المتطلب اكتمال تنفيذه. إذا تعارضت مصادر أو تواريخ أو قيم، يسجل التعارض ويوقف المسار المتأثر إلى أن يحسمه قرار صريح.

## 3. سيادة المالك وحدود الصلاحيات

- يوجد مالك بشري واحد للمنصة بهوية خادمية واحدة؛ Owner وSuper Owner تسميتان وصفيتان للشخص نفسه.
- لا ينقل التفويض ملكية المنصة. كل تفويض محدد بالنطاق والصلاحية والمدة وقابل للسحب والتدقيق.
- كل عملية حساسة تتطلب تحققاً خادمياً، أقل صلاحية، MFA/step-up حديثاً عند اللزوم، حماية من التكرار والتزامن، وسجل تدقيق غير قابل للتلاعب.
- لا دمج إلى `main`، ولا نشر، ولا تعديل موارد Firebase/Google Cloud الإنتاجية، ولا تفعيل Blaze أو فوترة أو موارد مدفوعة، ولا حذف إنتاجي، ولا تغيير سياسة احتفاظ حية، ولا إجراء مالي أو خارجي غير قابل للتراجع، ولا تغيير هوية تسجيل iOS دون موافقة مستقلة وصريحة على الإجراء ذاته.
- الموافقة العامة على التطوير لا تمنح موافقة على النشر أو الإنتاج أو الفوترة أو تغيير سياسات البيانات.
- لا تطلب كلمات مرور أو مفاتيح أو رموز وصول ولا ترفعها إلى المستودع.

## 4. الحوكمة والأدوار الإدارية

- **Super Owner:** المالك الوحيد.
- **Admin N:** إداريون عامون مفتوحو العدد، بأرقام متزايدة دائمة لا يعاد استخدامها، وصلاحيات صريحة مفوضة فقط.
- **Admin Media 1–5:** خمسة مقاعد مستقلة لقسم الإعلانات وMedia Workspace؛ لا يرثون صلاحيات المالك أو Admin N أو الإنتاج.
- **مشرف إنتاج عام 1–5:** خمسة مقاعد مستقلة للإنتاج العام.
- **مشرف إنتاج الفريق:** فئة مفتوحة العدد، محصورة بفريقه وغرفته.
- **المشرفون القانونيون/الإداريون:** أربعة مقاعد تخصصية لإدارة الوثائق والعقود؛ لا يملكون حق التوقيع إلا بتفويض توقيع مستقل وساري.
- فريق غرفة الإنتاج خمسة أشخاص كحد أقصى بمن فيهم المشرف؛ والمراقب الإداري المفوض خارج العدد.
- لا تفترض سياسة إعادة استخدام أرقام مقاعد Admin Media أو الإنتاج العام بعد الإزالة؛ المسألة معلقة حتى قرار صريح.
- الخادم هو مصدر الصلاحية، والافتراضي رفض الوصول (deny-by-default). الأسماء الظاهرة لا تمنح سلطة بذاتها.

## 5. الحسابات والعضوية والهوية

- تسجيل ودخول واستعادة آمنة، تحقق بريد موثوق، جلسات قابلة للإبطال، وبيانات عضو موحدة متسقة بين النماذج والخدمات وقاعدة البيانات.
- الحد الأدنى العام للعمر لا يقل عن 16 وفق المواصفة الحالية؛ أهداف التعارف/الزواج والخصائص الاجتماعية الرومانسية 18+ مع ضمان عمر مناسب ومراجعة قانونية قبل الإطلاق. لا يعد تاريخ الميلاد الذي يدخله المستخدم وحده إثباتاً للعمر.
- الضيف مسار محدود: بيانات تعريف قليلة، مدة استخدام محدودة وفق القرار المسجل، غرف all_ages، ولا محفظة أو متجر أو امتيازات العضو أو محادثات خاصة وفق الحدود الموثقة.
- إقرار الخصوصية الصريح والمحدد الإصدار مطلوب قبل إنشاء العضوية أو جلسة الضيف أو الوصول إلى محتوى محمي. لا موافقة ضمنية ولا خيار محدد مسبقاً.
- الملف الشخصي والخصوصية والروابط الاجتماعية والوسائط تخضع لتحقق خادمي. لا يعد لصق رابط دليلاً على ملكيته؛ يستخدم OAuth أو آلية تحقق معتمدة. لا تُمنح شارة غير مثبتة.
- حماية القاصرين ومنع تعدد الحسابات وإساءة الاستخدام متطلبات مستمرة وبوابات قبول.

## 6. التواصل والمحتوى والمجتمعات

تدعم المنصة الملفات الشخصية والاكتشاف والمنشورات والصور والفيديو والألبومات والتعليقات والتفاعلات والمشاركة والحفظ والقصص والمتابعة/الأصدقاء والزيارات وإعدادات الخصوصية، إضافة إلى المحادثات الخاصة والعامة وصندوق رسائل موحد والإشعارات والحظر والإبلاغ والاستئناف.

- كل قراءة وكتابة ووصول إلى محتوى خاص أو وسيط يفرض خادمياً، لا بمجرد إخفاء زر.
- مراجعة المالك للمحادثات أو الملفات قدرة شديدة الحساسية؛ تتطلب إفصاحاً واضحاً في الخصوصية، نطاقاً محدوداً، سبباً مشروعاً، تفويضاً، وسجل وصول. لا يجوز تحويلها إلى تدريب عام أو وصول غير محدود.
- لا تستخدم محتويات المحادثات الخاصة لتدريب عام دون أساس قانوني وموافقة منفصلة ذات معنى.
- أي ترويج مدفوع أو ترتيب مدفوع يجب تمييزه بوضوح.

## 7. الغرف والأحداث والحجوزات

- غرف عامة وخاصة ومستأجرة، مجتمعات وفعاليات وسعة مقاعد وRSVP.
- دورة الغرفة كاملة: التوفر، الحجز، الاستئجار، الدفع، الإلغاء، الاسترداد، انتهاء المدة ومنع الحجز المكرر.
- جميع الحجوزات والمعاملات خادمية وذرية وقابلة لإعادة المحاولة بأمان، مع سجل تدقيق وحماية من التزامن.
- صلاحيات المضيف والمشرف والعضو والمراقب محددة ومستقلة. لا تتوسع صلاحية غرفة إلى غرفة أو فريق آخر.

## 8. المكالمات والتسجيلات الصوتية

- التسجيل الصوتي الحي داخل المحادثات والغرف محدود بحد أقصى **60 ثانية**، ويفرض في الواجهة والخادم والاختبارات.
- لا يخلط التسجيل الحي بملف صوتي مسجل/مرفق.
- مدة المكالمة الحية وحصص الصوت/الفيديو منفصلة عن حد التسجيل، وتخضع للقيم المعتمدة في سجل القرارات. مواصفة 5 دقائق للمكالمة و5 محاولات صوتية و3 مرئية لكل 24 ساعة مسجلة في الوثائق؛ يجب الرجوع إلى أحدث قرار صريح عند أي تعديل.
- المكالمات المفتوحة المدفوعة لا تفعل قبل إغلاق metering وتوزيع التكلفة والتقريب وموافقة الأطراف والخصم الذري والدفتر والاختبارات وموافقة التفعيل المستقلة.

## 9. الوسائط والاحتفاظ وMedia Saver

الحدود التقنية العليا:
- الصور: 3 MiB.
- GIF: 3 MiB، 20 ثانية، 50 إطاراً.
- الصوت: 5 MiB و60 ثانية.
- الفيديو الأصلي: 25 MiB.
- مشتق الفيديو الآمن: 15 MiB وحتى 90 ثانية.
- PDF: حتى 20 MiB للمالك المثبت فقط.

هذه حدود قصوى وليست حصصاً أو أسعاراً. يجب التحقق من نوع الملف الفعلي والحجم والمدة والأبعاد والملكية، والفحص الأمني والحجر والتحويل الآمن وروابط الوصول المقيدة.

**Mawdda Media Saver** خدمة موحدة لحفظ الوسائط محلياً، مع تحقق خادمي من الاستحقاق عند كل عملية حفظ؛ ولا يمدد الحفظ المحلي مدة الاحتفاظ السحابي.

أوضاع الاحتفاظ المسجلة:
- مؤقتة للمحادثة الخاصة: حذف كامل بعد 4 ساعات من آخر نشاط مسجل خادمياً.
- عادية: الوسائط 4 ساعات والنصوص 7 أيام.
- مهمة: الوسائط 4 ساعات والنصوص 30 يوماً.

**قرار غير محسوم:** من يختار الوضع وهل يتطلب موافقة الطرفين. لذلك لا تفعّل دورة حذف حية تعتمد على اختيار الوضع قبل حسم القرار وتوثيقه. يجب إبلاغ الطرفين بالسياسة المطبقة. تحفظ السجلات المالية والأمنية والقانونية وفق التزاماتها ولا تحذف عرضاً مع تنظيف الوسائط.

## 10. الاقتصاد وبيتاكوينز والمحفظة والمتجر

- محرك اقتصادي مركزي موحد للمحفظة و**بيتاكوينز** والتحويلات والدفتر والمتجر والمنتجات والاشتراكات والاستحقاقات والألقاب والأوسمة والمنح والمكافآت وتأجير الغرف والإعلانات.
- كل معاملة خادمية وذرية وقابلة للتدقيق، مع معرف فريد/idempotency، ودفتر حركات موحد، ولقطة سعر/سياسة وقت المعاملة.
- مدد الاستحقاق المعتمدة: 24 ساعة، 7 أيام، و30 يوماً ثابتة (لا شهر تقويمي)، والمنتجات الدائمة عند اعتمادها. الأسعار والحصص والكميات يحددها المالك؛ لا تخترع قيمة أو سعر.
- منح المالك المجانية فردية أو جماعية أو لمستحقي غرفة/مجموعة وفق لقطة المستفيدين عند التنفيذ، مع سبب وسجل تدقيق ومنع تكرار الطلب التقني نفسه دون منع منحة جديدة مقصودة.
- طلب شراء بيتاكوينز يمر بمراحل واضحة؛ تعليمات التحويل لا تثبت الاستلام. لا يصدر الرصيد إلا بعد تحقق المالك من الدفع الخارجي وتأكيد خادمي ذري مع سجل.
- الدفع الآلي خيار مستقبلي مستقل، يتطلب مزوداً معتمداً وتحقق server-to-server وتوقيعاً وتسوية واستردادات ومكافحة احتيال ومراجعة قانونية ومالية وموافقة تفعيل مستقلة.
- إعدادات الأسعار والعملة والدقة ووسائل الدفع للمالك. غياب السعر المعتمد يعني عدم إتمام المعاملة.
- المطابقة المالية للقراءة فقط افتراضياً؛ لا تصحح الأرصدة التاريخية تلقائياً.
- لا تعامل تغيير رصيد بيتاكوينز كاسترداد نقدي.

## 11. الإعلانات ومشاهدة الإعلانات والمكافآت

- تمييز الإعلانات التجارية الممولة من المعلن عن مشاهدة الأعضاء ومكافآتها، وعن عمولات المندوبين وإيراد الشركة.
- قسم **مشاهدة الإعلانات** موجود ضمن تجربة العضو، ويجب الحفاظ على مدخله ووظيفته وعدم استبداله باسم آخر دون قرار. يشمل العرض المؤهل حسب الاستهداف الجغرافي ومشاهدة الإعلانات المميزة. الزر العائم اختصار للمميزة وليس قسماً ثالثاً.
- لا تمنح مكافأة لمجرد فتح الشاشة أو المعاينة أو تدوير البطاقات. تتطلب مشاهدة مؤهلة مثبتة خادمياً، foreground/visibility وheartbeat ومدة/نسبة إكمال وحدود ميزانية ومنع replay والتزامن ودفتر ذري.
- القيم التجريبية المسجلة في ADS-REWARD-001 (2 بيتاكوينز للمشاهدة المؤهلة، 10 مشاهدات/20 يومياً UTC، 3 مرات للحملة/العضو/نافذة 24 ساعة، صورة 10 ثوان وفيديو 90%) لا تفعل قبل مواءمة التنفيذ والاختبارات الخادمية وموافقة التفعيل.
- الحملات والمحتوى والنشر والاستهداف والميزانيات والأسعار والموافقة النهائية تحت سيطرة المالك.
- لا مزود إعلانات خارجي فعال قبل الاختيار والمراجعة والتكامل الموثوق.

## 12. Media Workspace والإنتاج وصناع المحتوى

- مساحة عمل مستقلة لإدارة دورة الإنتاج والإعلانات وصناع المحتوى والمقترحات.
- تشمل المسارات الموثقة: استقبال الطلبات، الإعلانات، الإنتاج، المواد/الأصول، ومقترحات صناع المحتوى والمؤثرين؛ تراجع أسماء المسارات الفعلية في مواصفة المجال قبل أي إعادة تسمية.
- دورة العمل: طلب/فكرة، تصنيف واستهداف، مراجعة، تعيين صلاحيات، تخطيط فريق، غرفة إنتاج، تسليم المادة، مراجعة السلامة والجودة والحقوق، موافقة المالك، نشر أو أرشفة.
- لا نشر أو إعلان مكتمل دون موافقة المالك المستقلة حيث تتطلب السياسة.
- لا تخلط Admin Media بمشرف الإنتاج العام أو مشرف إنتاج الفريق أو Admin N.

## 13. التوثيق البيومتري ومصادقة الجهاز

مساران مستقلان:
1. **توثيق يدوي بمراجعة Super Owner:** طلب اختياري بعينة صوت لعبارة تحدٍ وفيديو حي قصير 3–5 ثوانٍ، مراجعة بشرية، طلب نشط واحد، ثلاث محاولات إجمالية، وقفل ثلاثة أشهر بعد رفض الثالثة. القبول يمنح شارة ومكافأة **1,500 بيتاكوينز** مرة واحدة للعملية، بعد تحقق خادمي ذري وسجل. التجديد شهري تقويمي وفق القرار. مكافأة البريد 500 بيتاكوينز كل ثلاثة أشهر تقويمية مستقلة. الأدلة مؤقتة ومشفرة وخاصة وتحذف بعد القرار وفق إجراء قابل للتدقيق، مع الاحتفاظ بسجل تشغيلي أدنى.
2. **مصادقة الجهاز المحلية:** تثبت حضور المستخدم على جهازه فقط، ولا تثبت هوية مدنية أو liveness أو قرار التوثيق اليدوي، ولا تمنح الشارة أو المكافأة.

لا تفعّل الدورة قبل اكتمال الموافقة والإفصاح والتخزين الخاص والصلاحيات والحذف والإشعارات والدفتر والاختبارات. أي مزود خارجي أو إثبات تشفيري يحتاج قراراً مستقلاً.
