## بوابات الإغلاق الحرجة — غير مكتملة
1. تشغيل Cloud Run ClamAV فعلياً في مشروع غير إنتاجي مستقل وربطه بـ Functions والتحقق من IAM وSecret Manager وتحديث التواقيع.
2. تشغيل اختبار E2E حي من Functions إلى Cloud Run ثم callback ثم Cloud Storage، بما يشمل ملفاً نظيفاً وEICAR والمهلات والتوقيع الخاطئ وإعادة المحاولة والتنظيف.
3. اختبار روابط PUT/GET الموقعة على bucket غير إنتاجي حقيقي، والتحقق من الحجم وCORS وإعادة الاستخدام وانتهاء الصلاحية والأجيال.
4. إكمال معاينة المالك الآمنة عبر مشتقات معاد ترميزها، وعدم عرض الملفات الأصلية غير الموثوقة مباشرة.
5. إكمال واجهة ومسارات إرسال واستقبال وسائط المحادثات للصور وGIF والفيديو والصوت.
6. فرض حظر PDF والمستندات على الأعضاء في واجهات العميل والخادم وقواعد التفويض؛ والسماح بها حصراً للمالك/Super Admin الموثق خادمياً. يجب اختبار تجاوز الواجهة وطلبات API المباشرة.
7. التحقق من حذف الوسائط والقصص والملفات الشخصية وسياسة الاحتفاظ القانونية والنسخ الاحتياطي والاستعادة وPITR وسلسلة التدقيق.
8. إكمال إشعارات الرسائل والحظر والإبلاغ والاستئناف وبقية مسارات إساءة الاستخدام وسلامة العمر.
9. إكمال فوترة الغرف، التحقق البيومتري عبر مزود معتمد، دورات التجديد ومكافآتها، ومزايا المتجر المعتمدة قبل وصفها بأنها حية.
10. إكمال مراجعة الخصوصية القانونية، إقرار الضيوف، دورة حياة الضيف غير المسجل، ومراجعة وصول المالك وتصدير التدقيق.
11. تنفيذ اختبارات أمنية مستقلة، واختبارات أجهزة ومتصفحات وأداء وإمكانية وصول، وخطة استعادة موثقة.
12. إعداد قائمة إصدار نهائية تربط كل مطلب مع commit واختبار ونتيجة وتاريخ وأثر تشغيلي.

## سياسة PDF والمستندات
- أعضاء المنصة: لا إرسال ولا استقبال PDF أو مستندات في المحادثات أو الغرف.
